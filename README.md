## Publicação
Extraia o conteúdo sobre `D:\dzbot-site`:

```powershell
cd D:\dzbot-site
git add .
git commit -m "DZbot V9 Gold Master"
git pull --rebase origin main
git push origin main
```

Não use `git push --force`.

## Publicar
Extraia tudo sobre `D:\dzbot-site` e execute:

```powershell
cd D:\dzbot-site
git add .
git commit -m "DZbot RubinOT Premium V4"
git pull --rebase origin main
git push origin main
```

Não use `git push --force`.
